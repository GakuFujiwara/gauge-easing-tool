# Gauge Easing Tool

ゲージのイージング曲線を作るブラウザツールです。単一の `index.html` だけで動きます（ビルド・依存なし）。

- ボタンを押している間だけゲージが進み、離すとリセットされます（Space キーも可）
- 100% までの秒数を指定できます
- アンカーを追加して曲線を編集できます（ベジェ曲線、ダブルクリックで追加・削除）
- プログラムに組み込みやすい形で書き出せます
  - ベジェ制御点（セグメント配列）／等間隔サンプル表
  - JSON / JavaScript / Swift / C# (Unity) / C++ / Python / CSV
  - AI に貼り付けて実装を頼むための説明文（秒数・検算表・参考実装つき）
